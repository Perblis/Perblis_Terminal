# Terminal v2 — Decision Log (moved)

**This file is no longer the decision log.** The canonical, single decision authority is:

## → [DECISIONS.md](../../DECISIONS.md) (repository root)

Moved under **D-031** when the repository adopted the governance-system document layout.

**No decision was rewritten.** D-001…D-030 carry their original date, wording and detail
verbatim; the move added a `Status` column (recording supersessions that were previously
only implied in prose), an **Observations** table for non-binding facts read from the
code, and an **Open items** table with stable `O-###` IDs for the follow-ups that used to
sit as loose bullets at the bottom of this file.

Any citation of the form `D-018` resolves against the root file unchanged. Decisions are
never silently edited — a change of intent creates a new D-ID that marks the old one
superseded.
